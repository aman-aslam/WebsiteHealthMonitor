# Security Policy

## Supported versions

Security reports are welcome for the current default branch of this repository.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or pull requests.

Use GitHub's **Report a vulnerability** option in the repository's Security tab (private vulnerability reporting / security advisories) when available. Include:

- A clear description of the issue and its potential impact.
- Steps to reproduce the issue, including relevant request examples.
- Any suggested mitigation, if known.

Please avoid including real customer data, credentials, access tokens, or other secrets in a report.

## Response

Reports will be reviewed as soon as reasonably possible. Please allow time for investigation and a fix before sharing details publicly.
